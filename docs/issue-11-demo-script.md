# 이슈 11 대표 시연 순서

실제 배포 URL의 동작을 확인한 뒤 사용합니다. 시연에는 개인정보가 없는 테스트 일정을 사용하고, 배포 검증이 끝나지 않았다면 완료된 것처럼 소개하지 않습니다.

## 2~3분 시연

1. **서비스 소개** — “틈새는 등록된 내 일정과 가능 시간을 기준으로 빈 시간을 찾고, 확인 후 저장하는 개인 AI 스케줄러입니다.”
2. **로그인·일정 확인** — 카카오 로그인 후 선택일과 주간/월간 달력을 보여줍니다.
3. **빈 시간 검색** — “내일 1시간 빈 시간 찾아줘”처럼 날짜와 길이가 분명한 요청을 보냅니다. AI 응답과 후보 카드가 같은 시간인지 확인합니다.
4. **후보 선택** — 후보 하나를 선택하고 해당 시간으로 일정을 준비해 달라고 말합니다.
5. **등록 전 확인** — 등록 확인 카드에서 제목·날짜·시간을 검토합니다. 사용자가 누르기 전에는 저장되지 않는다는 점을 설명합니다.
6. **실제 저장 확인** — 확인 버튼을 누르고 달력에 일정이 나타나는지, 새로고침 후에도 유지되는지 보여줍니다.
7. **제한 설명** — “현재 등록된 일정과 가능 시간 기준이며 외부 캘린더·이동 시간은 고려하지 않습니다.”
