# 주간·월간 달력 전환 디자인

## 목적
손 대표님이 샘플 일정의 한 주 시간 배치와 한 달 분포를 오가며 날짜를 고를 수 있게 한다. 현재의 선택일 목록과 AI 후보·등록 확인 흐름은 선택한 날짜를 기준으로 계속 동작한다.

## 접근 방식
- **선택: 7열 월간 격자.** 데스크톱에서 한 달을 훑기 좋고 기존 주간 달력 카드 안에서 전환할 수 있다.
- 대안: 날짜별 세로 목록. 일정 제목은 읽기 쉽지만 한 달의 빈 날과 바쁜 날을 한눈에 비교하기 어렵다.
- 대안: 월간 격자와 별도 상세 화면. 작은 샘플 화면에 불필요한 이동을 더한다.

## 화면과 동작
- 달력 제목 옆에 `주간`·`월간` 두 버튼을 둔다. 선택한 보기의 버튼은 색과 `aria-pressed`로 구분한다.
- 보기 전환은 선택 날짜를 유지한다. 월간으로 바꾸면 선택 날짜가 속한 달, 주간으로 바꾸면 그 날짜가 속한 월요일 시작 주를 보여준다.
- 이전·다음은 주간에서 7일, 월간에서 1개월씩 이동한다. 월간 이동 시 새 달의 1일을 선택하고 선택일 목록·AI 검색 기준을 함께 갱신한다. `오늘`은 오늘 날짜를 선택하고 해당 보기로 이동한다.
- 월간 격자는 월요일부터 시작하며 앞뒤 달 날짜도 칸을 채워 표시한다. 옆 달 날짜는 옅게 표현하고 누르면 그 달로 이동한다.
- 데스크톱 날짜 칸은 날짜와 일정 제목 최대 2개, 추가 일정 건수를 보여준다. 모바일은 날짜와 작은 일정 표시·건수를 보여주고 제목은 선택일 목록에서 읽는다.
- 오늘은 테두리, 선택한 날은 채운 배경으로 구분한다. AI가 제안한 선택 후보가 있는 날짜는 별도 점선 표시를 사용한다.
- 날짜를 누르면 기존 선택일 목록이 바뀐다. 기존 `selectDate` 동작대로 다른 날짜의 AI 후보는 초기화해 이전 날짜 후보를 등록하지 않게 한다.
- 샘플 확인으로 추가한 일정은 월간 표시와 선택일 목록에 즉시 반영된다. DB 저장이라는 표현은 쓰지 않는다.

## 범위와 제약
- 현재 샘플 일정 화면 안의 UI 변경이다. 인증·DB·실제 AI·MCP 연결은 포함하지 않는다.
- 기존 색상·글꼴·카드 스타일을 유지하고 새 달력 의존성은 추가하지 않는다.
- 키보드로 모든 날짜와 전환 버튼을 누를 수 있고 날짜 버튼은 전체 날짜를 읽을 수 있는 이름을 제공한다.
- 모바일에서는 달력과 선택일 목록이 세로로 이어지고 하단 AI 질문 바를 가리지 않는다.

## 완료 기준
- 주간·월간 전환과 날짜 선택, 주·월 이동, 오늘 복귀가 데스크톱·모바일에서 작동한다.
- 월말·연말 이동과 4~6주에 걸친 월 표시가 정확하다.
- 후보 선택 → 등록 확인 → 샘플 일정 추가 흐름이 두 보기에서 일관된다.
- 타입 검사·린트·테스트·빌드가 통과하고 실제 브라우저에서 두 화면 폭을 확인한다.
