# 일정 가능 시간 설계

## 의도

사용자가 평소 일정 추천을 받아도 되는 시간과 휴가 등 특정 날짜의 불가 시간을 설정한다. 이를 `활동 시간` 대신 `일정 가능 시간`이라고 부른다.

## 사용자 확인 사항

- 요일별로 가능한 시간을 다르게 설정한다.
- 특정 날짜나 날짜 구간을 하루 전체 일정 불가로 지정할 수 있다.
- 일정 가능 시간은 AI의 빈 시간 추천 범위를 정한다. 직접 일정 등록은 허용한다.
- 일정 간 실제 충돌은 기존처럼 등록을 막는다.
- 모든 요일의 기본 가능 시간은 09:00~21:00으로 두고, 사용자가 요일별로 수정할 수 있다.

## 목표

- 월요일부터 일요일까지 요일별 가능 시간대를 설정하고 사용자가 선택한 요일은 끌 수 있다.
- 하루에 둘 이상의 가능 시간대를 설정해 점심·저녁처럼 떨어진 시간을 표현할 수 있다.
- 휴가·개인 사정은 시작일과 종료일을 포함하는 하루 전체 불가 예외로 등록한다.
- AI 빈 시간 계산은 요청 구간, 해당 요일의 가능 시간대, 날짜 예외, 기존 일정을 모두 적용한다.
- 시간대는 `Asia/Seoul`로 고정한다. 설정 변경은 기존 일정을 지우거나 이동시키지 않는다.

## 범위 밖

- 근무 일정 자체의 반복 등록, 외부 캘린더 동기화, 공휴일 자동 조회.
- 특정 날짜만 평소와 다르게 열어두는 사용자 지정 시간대.
- AI 빈 시간 검색 구현 자체. 현재 서비스에 검색 기능이 없으므로 이 설계는 향후 검색 구현의 입력 계약을 정한다.

## 접근 방식

1. 매일 공통 시작·종료 시각을 설정한다. 구현이 단순하지만 평일 퇴근 후와 주말 시간을 구분하지 못한다.
2. 요일별 반복 가능 시간대와 날짜별 전체 불가 예외를 둔다. 일상 패턴과 휴가를 표현하면서도 달력 전체를 편집하는 복잡성을 피한다. **선택한 방향**이다.
3. 모든 바쁜 시간과 반복 일정을 달력에서 직접 관리한다. 직장·외부 캘린더 연동을 포함하게 되어 현재 범위를 크게 넘는다.

## 화면과 동작

- 경로는 `/schedule/settings`로 제안한다. 일정 화면에 `일정 가능 시간` 진입 버튼을 둔다.
- 요일별로 사용 여부를 켜고 끄며, 각 요일에 한 개 이상의 15분 단위 시간 구간을 추가·삭제한다. 구간은 같은 날 안에서 시작보다 늦은 종료를 가져야 하고 서로 겹치지 않는다.
- `일정 불가일` 영역에서 날짜 또는 날짜 구간과 선택적인 이름(예: 휴가)을 저장한다. 날짜 구간은 시작일·종료일 모두 포함한다. 예외 날짜의 추천 가능 시간은 0이다.
- 모든 요일의 기본값은 09:00~21:00이다. 설정 화면에서 요일을 끄거나 시간 구간을 바꿀 수 있다.
- 설명 문구는 “여기에 설정한 시간에 AI가 빈 시간을 추천해요. 직접 일정은 언제든 등록할 수 있어요.”로 제안한다.
- 가능 시간 설정과 휴가 변경은 기존 일정을 삭제·변경하지 않는다. 일정이 가능 시간 밖에 있더라도 일정 목록과 충돌 검사에는 계속 포함한다.
- 설정이 바뀌면 설정 버전을 올린다. 향후 AI 제안은 버전이 달라졌을 때 기존 후보를 그대로 확정하지 않고 다시 계산한다.

## 데이터·서버 제안

- 사용자별 요일 반복 규칙과 시간 구간을 저장한다. 한 요일에 여러 구간을 허용하기 위해 `user_settings.day_start/day_end` 한 쌍으로 표현하지 않는다.
- 날짜 예외는 소유자별 날짜 구간과 선택적 이름으로 저장한다. 서버는 인증된 사용자 ID를 사용하고 직접 테이블 쓰기를 열지 않는다.
- 기존 공통 설정은 해당 사용자의 7일 규칙으로 변환해 값이 달라지지 않게 한다. 아직 설정 행이 없는 사용자의 초기값은 7일 모두 09:00~21:00이다.
- 빈 시간 계산은 요청 시간대 ∩ 요일 가능 시간대 − 날짜 불가 예외 − 기존 일정 순서로 계산한다.
- 일반 일정 등록은 가능 시간 규칙으로 차단하지 않는다. 일정은 업무 미팅 등 사용자의 모든 기록을 담고, 가능 시간 규칙은 추천 가능 범위에만 적용한다.

## 수용 기준

- 설정 화면에서 7일 규칙과 여러 시간 구간을 저장하고 새로고침 후 복원한다.
- 잘못된 구간, 겹치는 구간, 15분 단위가 아닌 입력은 저장되지 않는다.
- 특정 날짜 구간을 전체 불가로 저장하고 주간 반복 규칙보다 우선 적용한다.
- 사용자가 일반 일정으로 근무 시간대 일정을 기록할 수 있고, 해당 일정은 이후 빈 시간 추천에서 점유 시간으로 취급된다.
- 가능 시간이나 휴가 변경으로 기존 일정을 삭제·수정하지 않는다.
- 사용자 간 규칙·예외가 격리되고, 인증·저장 실패 상태를 화면에서 구분한다.

## 남은 결정

- 휴가 예외의 선택적 이름과 날짜 구간 최대 길이는 구현 시점에 제안하고 확정한다.
- AI 빈 시간 검색 기능이 추가될 때 이 설계의 추천 범위 규칙을 실제 계산 서비스에 연결한다.
